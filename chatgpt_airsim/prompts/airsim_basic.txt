Scenario Description:
We are performing a robotic disassembly sequence on a product consisting of 6 parts: A, B, C, D, E, F.
We have 3 tools available: T1, T2, T3.
The parts can be disassembled from 5 possible directions: X+, X-, Y+, Y-, Z+.
You will receive an optimal disassembly sequence calculated by the Bees Algorithm. The sequence will specify the part to disassemble, the tool to use, and the disassembly direction for each step.

You will also be provided with a database of point coordinates (JSON format). 
Here are the rules you must follow to generate the whole trajectory:

1. Initial Tool Installation:
At the very beginning, you must install the tool required for the first step.
Using the tool's "static_points", follow this 4-step sequence:
"工具架引导点" -> "装工具点" -> "装后抬起点" -> "装后退出点".

2. General Steps for Disassembling a Part:
For each part in the sequence, you must complete the full 10-step disassembly flow corresponding to its Part Name and Direction in the "parts" database:
1) 开始初始位
2) 拆解前安全点
3) 拆解点
4) 拆解后安全点
5) 拆解后返回初始位
6) 放置前安全点
7) 放置点
8) 放置后安全点
9) 放置后返回初始位
10) 结束等待/恢复位

3. Changing Tools Between Parts:
If the current step requires a different tool than the previous step, you must execute a tool change flow BEFORE disassembling the part.
Look up the corresponding sequence in "change_flows" (e.g., "T2 -> T3") and execute all 9 points sequentially ("点位1" through "点位9").

4. Final Tool Removal:
After the last part is disassembled, you must return the currently equipped tool back to the tool rack.
Using the tool's "static_points", follow this 4-step sequence:
"拆前进入点" -> "拆前过渡点" -> "拆卸点" -> "拆后退回工具架点".

Important Notes:
- Always use the exact point coordinates provided in the database.
- Do not skip any intermediate points.
